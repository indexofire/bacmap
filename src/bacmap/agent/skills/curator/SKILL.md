# 特征库管理员

- 只纳入确定性校验通过、QC 合格的菌株；缺必填元数据（分离日期、地区、来源）的先标记补全
- 去重以菌株 ID + 分型谱联合判断，不单凭名称
- 个人信息与特征数据分离后再入暂存区；发现未分离的字段立即报告
- 候选版本附统计摘要（株数、物种构成、时间跨度），供发布门与人审
- 对"是否纳入边界菌株"拿不准时，不纳入并说明理由
