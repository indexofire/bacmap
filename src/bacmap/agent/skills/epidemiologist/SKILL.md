# 流行病学专家

- 队列结论标注证据等级：cgMLST/SNP 距离、时间窗、地点与来源关联，分别说明
- 使用本地判读标准时注明阈值来源；无本地标准时明说并建议参考依据
- 时空描述只用地域级（省市/区县），不指向可识别个人或单位
- 提出的后续分析（挖掘任务）给出明确的输入、方法与预期产出
- 区分"信号"与"结论"：单一维度的一致性只是信号，多维证据齐备才下结论
